# Мой дневник

Система для ведения личного дневника: удобное мобильное приложение для Android
и десктопное приложение для Windows для анализа всех записей на большом экране.

```
Дневник/
├── mobile/             ← мобильное приложение (Flutter, Android)
│   └── lib/
│       ├── main.dart
│       ├── theme/app_theme.dart          тёмная палитра
│       ├── models/diary_entry.dart        модель записи
│       ├── services/storage_service.dart  хранение + пароль + экспорт
│       ├── utils/ru_date.dart             русские даты
│       └── screens/
│           ├── lock_screen.dart           экран пароля
│           ├── home_screen.dart           календарь + список
│           └── editor_screen.dart         редактор записи
│
├── desktop/            ← приложение для ноутбука (Python + Tkinter)
│   ├── diary_desktop.py                   вся логика и интерфейс
│   ├── make_samples.py                    генератор тестовых записей
│   ├── sample_entries/                    примеры записей (для теста)
│   └── Запустить дневник.bat              запуск двойным кликом
│
└── README.md           ← этот файл
```

## Как это работает

**Формат записей.** Один день = один файл `ГГГГ-ММ-ДД.txt` (например
`2025-03-14.txt`). Внутри:

```
=== 2025-03-14 ===

— Прогулка —

Долгая прогулка у реки. Думал о будущем...
```

Такая структура понятна и человеку (обычный txt), и обоим приложениям —
они раскладывают записи по датам и строят календарь.

## 1. Мобильное приложение (Android)

### Что умеет
- **Пароль при запуске.** При первом старте просит придумать пароль
  (мин. 4 символа), хранит только его хэш (SHA-256) — на сервер ничего не уходит.
- **Календарь.** Все дни с записями отмечены точкой. Тап по дню — записи этого дня.
- **Редактор.** Заголовок + текст, автосохранение через секунду после паузы,
  счётчик слов, привязка к дате.
- **Несколько записей в день** (утро/вечер и т.п.).
- **Экспорт в TXT.** Кнопка «Поделиться» сверху → сохраняет/отправляет
  txt-файлы по датам (папка `DiaryExport`), удобно перекинуть на ноутбук.

### Сборка APK (установочного файла)

Нужен **Android Studio** (он же поставит Android SDK). Это разовая настройка:

1. Установите [Android Studio](https://developer.android.com/studio),
   при первом запуске примите установку SDK (Android SDK + Platform-Tools).
2. Проверьте, что Flutter видит SDK:
   ```
   flutter doctor
   ```
   Должно быть `[√] Android toolchain`.
3. В папке `mobile` выполните:
   ```
   flutter build apk --release
   ```
4. Готовый файл появится тут:
   ```
   mobile\build\app\outputs\flutter-apk\app-release.apk
   ```
5. Перекиньте `app-release.apk` на телефон (кабелем, облаком, мессенджером),
   откройте его на телефоне и разрешите установку из неизвестных источников.

### Проверка интерфейса прямо сейчас (без Android Studio)

Пока APK не собран, интерфейс можно посмотреть в браузере — он полностью
рабочий (пароль, календарь, редактирование, сохранение):

```
cd mobile
flutter run -d chrome
```

## 2. Приложение для ноутбука (Windows)

### Что умеет
- Читает папку с txt-файлами (экспортированными с телефона).
- **Календарь** — дни с записями отмечены; тап по дню показывает записи.
- **Поиск** по всем записям (мгновенный).
- **Просмотр** записи справа.
- **Статистика:** всего записей, всего слов, среднее число слов,
  текущая серия дней подряд, период, самая длинная запись.

### Запуск
- **Проще всего:** двойной клик по `desktop\Запустить дневник.bat`.
- Или из терминала:
  ```
  python desktop\diary_desktop.py
  ```

Зависимостей ставить не нужно — используется только стандартная библиотека
Python (tkinter уже входит в него).

### Как открыть записи с телефона
1. На телефоне: «Поделиться» (иконка экспорта) → сохранить txt-файлы
   (они лягут в `DiaryExport`).
2. Скиньте эту папку на ноутбук (кабелем/облаком).
3. В десктоп-приложении: кнопка **«Открыть папку с записями»** → выберите папку.

Приложение запоминает последнюю папку и при следующем запуске открывает её
автоматически.

### Быстрый тест без телефона
В папке уже лежат готовые примеры — `desktop\sample_entries`.
Запустите приложение и откройте эту папку, чтобы увидеть, как всё выглядит.
(Пересоздать примеры: `python desktop\make_samples.py`.)

## Приятные детали

- Обе программы — в одной тёмной «графитовой» палитре с тёплым янтарным акцентом.
- Русские месяцы, дни недели, склонения («1 запись / 2 записи / 5 записей»).
- Пароль не хранится в открытом виде — только его хэш.
- Данные никуда не отправляются: телефон хранит всё локально, ноут читает файлы.
